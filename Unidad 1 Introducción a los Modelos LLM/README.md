# Preparacion de Entorno
### 1. Descargar e instalar Miniconda
Primero, descarga Miniconda desde el siguiente enlace:
[Miniconda Installer](https://docs.anaconda.com/free/miniconda/)

### 2. Instalar Miniconda
Sigue las instrucciones del instalador para instalar Miniconda en tu sistema. Asegúrate de seleccionar la opción para agregar Miniconda a tu PATH durante la instalación.

### 3. Abrir Anaconda Command Prompt
Una vez que Miniconda esté instalado, abre el "Anaconda Command Prompt". Puedes buscarlo en tu menú de inicio.

### 4. Crear un nuevo entorno con Miniconda
Usa el siguiente comando para crear un nuevo entorno. En este ejemplo, el nombre del entorno es `CursoIA`, pero puedes cambiarlo según tu preferencia.
```bash
conda create -n CursoIA
```

### 5. Activar el entorno
Después de crear el entorno, actívalo con el siguiente comando:
```bash
conda activate CursoIA
```

### 6. Instalar pip en el entorno
Instala `pip` en el entorno con el siguiente comando:
```bash
conda install pip
```

### 7. Instalar Jupyter
Finalmente, instala Jupyter usando `pip`:
```bash
pip install jupyter
```

### Resumen de comandos
```bash
# Crear un nuevo entorno
conda create -n CursoIA

# Activar el entorno
conda activate CursoIA

# Instalar pip
conda install pip

# Instalar Jupyter
pip install jupyter
```

### 8. Ejecutar Jupyter Notebook
Para asegurarte de que todo está instalado correctamente, puedes iniciar Jupyter Notebook con el siguiente comando:
```bash
jupyter notebook
```

Esto abrirá una ventana en tu navegador web donde podrás crear y gestionar tus notebooks de Jupyter.

Si necesitas alguna otra información o asistencia, no dudes en preguntar.
